# GridWorld — project rules

Browser FPS in a green vector-grid style (wireframe on black, retro sci-fi / Tron / CRT terminal).
`legacy/grid-arena.html` is the original single-file version (from when the game was called Grid Arena), kept as the reference for behaviour.

## Commands
- `npm run dev` — dev server (Vite)
- `npm test` — Vitest (generators, terrain, saves)
- `npm run typecheck` / `npm run build`
- Dev console: ~ (Backquote) opens it in every build (`ui/console.ts`): `cash` (+10000 gold), `god` (full health + immortality, toggle), `home` (back to Gridholm), `time [hour]` (show the clock / skip ahead), `help`, `clear`. Add commands to `COMMANDS` there.
- In a dev build, `window.__game` exposes `{ G, W, camera, scene, renderer }` for debugging; F3 toggles the perf overlay (fps, lines, triangles, draw calls).

## Rules
- **After every finished task** (committed and pushed), end the reply with the download link of the current version: `https://github.com/MrFischoeder/Gridworld/archive/refs/heads/<branch>.zip` (the branch the work was pushed to). Unzip, `npm install`, then `start-gry.bat` or `npm run dev`.
- **Version label:** bump `VERSION` in `src/version.ts` (shown in the pause menu) with every pushed feature, so the owner can tell which build is running.
- **Stack:** Vite + TypeScript (strict), three.js from npm. No UI framework: HUD and windows are plain DOM + CSS.
- **Game language: English.** Every player-visible text (HUD, menus, dialogue, items, hints) is English. Identifiers and comments in English.
- **Deterministic generation:** the whole world (dungeons, villages, terrain, ruins, object placement) comes only from seeded RNG (`core/rng.ts`: `rng`, `hash`, noise). Generators **never** call `Math.random()`. `Math.random()` is allowed only for effects and unsaved things (sparks, drone loot, NPC wandering). Same seed + same coordinates = identical result. This is the basis of saves and future multiplayer.
- **Save only player changes** (opened chests, killed bosses, unlocked doors, position, character) — never generated geometry.
- **Visual style:** grid lines `#2fe060`, black background, fog to black (on the surface by day the sky and fog turn a dark green, see the game clock note). Every solid that should hide what is behind it needs a dark fill (e.g. `0x010d04`, see `fillMat()` in `world/render.ts`) with `polygonOffset`, lines on top. Lines without a fill are see-through — a bug, unless the object is meant to be openwork (drones, bosses, pickups).
- **Functional colours:** drones and hostile creatures `#ffb347` (a calm Bramble is olive `#b8b060`), bosses `#ff6a4a`, gold/chests `#ffd060`, stairwells `#5cc8ff`, XP `#9dffe0`, locked doors `#ff5a3c`; water: fresh `#2ac8b0`, murky `#8a9a4a`, toxic `#b6ff3a` (glowing).
- **Controls: desktop only for now** (pointer lock, WASD, mouse). Mobile/touch development is paused: keep the existing touch code (joystick, buttons in `ui/touch.ts`) in place, but new features do not need touch controls, touch layouts or phone testing, and mobile is not considered in design decisions until the owner says otherwise.
- **Performance:** smooth on an average laptop (phones are out of scope while mobile is paused). Measure line/triangle counts (F3) on big changes.
- **Map format:** voxel maps are ordered op lists `{op:'room'|'solid', x,y,z,w,h,d}` (later ops override earlier). The future map editor will save this format — keep it.
- **Multiplayer later** (up to 8 players, Node + WebSocket, authoritative server): keep world logic (`core/`, `gen/`) free of three.js and DOM, generators deterministic, game state serialisable.

## Layout
- `core/` — pure: RNG/hash, voxel grids, meshing, noise.
- `gen/` — pure generators: dungeon, stairs, village, doors placement, reachability; open world: `regions` (256 m regions, POIs), `terrain` (heightfield, flattening), `roads`, `ruins`, `trees`.
- `world/` — runtime with three.js: player, doors/stairs, enemies, loot, NPCs, `level` (loading places, transitions), `overworld` (chunk streaming, structures, field enemies).
- `ui/` — DOM: HUD, minimap, `worldmap` (surface minimap + M map), backpack, dialogue, menu, input, touch.

## Open world notes
- Regions (rx, rz) span [rx*256-128, rx*256+128); region (0,0) holds Gridholm at the origin. New place types = new `PoiType` + a placement rule in `gen/regions.ts`.
- The planet (`gen/regions.ts`): the world wraps east-west after `NR` = 470 regions (`WORLD_W` ≈ 120 km, canonical x in [`X_MIN`, `X_MIN + WORLD_W`)); north and south it ends at the poles (ice caps from `POLAR_Z` = 25 km: no places, no forest, pale ice lines; an ice wall at `POLE_Z` ≈ 30 km that the player cannot pass). Generators take any coordinates but work in canonical ones: `regionInfo`/`chunkTrees`/`chunkRocks`/`regionVehicle` fold `rx`/`cx` with `wrapR`/`wrapC` and shift the result to the requested copy, so ids and save keys are the same on both sides of the seam; noise repeats through `fbm(..., px)` with scales adjusted by `wrapScale` (near Gridholm the land is practically unchanged). At runtime `keepOnPlanet` moves the player (and vehicles, loot; foes are dropped) to the other copy when crossing the seam and rebuilds the chunks. Distances to saved places use `worldDist` / `nearX` / `wrapDx`. Big static meshes use `localize()` (small local vertices, offset in the object position) so lines do not shimmer tens of km from the origin. The sun's path tilts with `latitude(z)` (`sunTilt`): high at the equator, endless dusk at the poles. Danger is capped at 8.
- Villages (`gen/regions.ts`): Gridholm (`GRIDHOLM_ID`, region 0,0) plus one village in ~60% of the 10x10-region cells (~2.5 km; `allVillages` lists them, ~550 per world), named from syllables, never on the ice. Each is `generateVillage(villageSeed(world, poi), y, x, z, name, home)`: own layout, gates, roads to nearby ruins, residents with their own names (`Npc.town`; dialogue swaps 'Gridholm' for the town). Only Gridholm (`VillageMap.home`) has the notice board and Mirek's yard for now. Safe zones, holstered weapons and the no-spawn margins apply around every village (`villageContaining`, `villageDist`). Death and the Recall Beacon take you to the nearest village you have explored (`toVillage`); console `home` = Gridholm. Future multiplayer: villages (and later crash sites) are the spawn points.
- Line styles: dungeons keep the original 1 m grid on every face; surface structures use the outline style (`meshVoxels(..., outline)`: folds and edges, 2 m floor tiles, 4 m wall seams). Decorative non-voxel shapes (roofs, lookouts, gate arches, rocks) go through `PropBatch` — collision stays on voxels.
- Trees (`gen/trees.ts` pure, `world/trees.ts` models): candidate spots never change (`treeTrunks`, used for vehicle placement); each spot's kind comes from its own hash: pine (high ground), broad (default), and the big T-01 Ancient Twisted, T-02 Umbrella and T-03 Hollow Arch (walk-through; one collision circle per leg, `Tree.cols`). Big trees (`TREE_SPAN`) clear small ones around them, also across chunk borders, and keep off roads and places. Models are faceted tubes, crowns and canopies in a PropBatch with a far LOD.
- Water (`gen/water.ts` pure, `world/water.ts` runtime): lakes per region (`regionLakes`, ~30%, more in low ground; never on the ice, near places or roads), each a still surface (`level`) over a bowl carved into the terrain (`lakeBed`, applied in `Terrain.exact` via `Features.lakes`) with a low lip just past the shore so water never spills; kinds fresh / murky (low valleys) / toxic (near ruins). Ask `Terrain.water(x, z)` → `{ level, depth, kind }`. Wells: every village well plus wild wells (`regionWells`, ~1 region in 4, drawn per chunk, solid). Player: wading slows, deeper than `SWIM_DEPTH` you swim at the surface with weapons away (diving later), toxic water hurts. E at water/wells drinks (fresh +8 HP, murky may hurt, toxic refused) or fills an Empty Flask (→ Flask of Clean / Murky Water; the flask is kept when drunk). Vehicles stop at water deeper than their spec `wade` (Scout 0.6 m, Mastodon 1.2 m); creatures and bandits avoid deep water. Thirst/food will build on this (see `useWater`). Rivers: not yet.
- Ruins are alien temples (`gen/ruins.ts`, 40 m square): a cross plan with a round inner wall and four broken arms; the crypt with the stairwell down sits behind a stepped portal between two leaning pylons that carried a great ring; an avenue of obelisks leads in. Collision and the stairwell are voxels (`ops`); the alien shapes are `RuinMap.temple` (temple-local u/v coordinates, `templeXZ`) drawn by `world/temple.ts` as PropBatch solids that enclose the voxels. Everything is rolled weathered: snapped pylons, a fallen or missing ring, broken/leaning obelisks with their tops lying by them, ragged tops, fallen blocks, rubble.
- Crash sites (POI type `wreck`, `WRECK_LEN` x `WRECK_WID` rect along x or z; ~14% of regions, ≥ 400 m from villages and 110 m from other places, `packId(rx, rz, 3)`, placed in `regionInfo`): `gen/wreck.ts` (pure) `generateWreck` gives hull-local frame (`wreckXZ`, u along the ship with the nose buried, v across), collision voxels as 2 m slices inscribed in the octagonal hull (`hullR`, `hullY`, `octHalf`), a side hatch with a vestibule and a stairwell going down towards the tail; `world/wreck.ts` `drawWreck` draws the hull (open over the hatch), nacelle with rings, fin (maybe snapped), cockpit windows, crack, hatch collar and ramp, debris. Inside (`loadDungeon` picks `gen/ship.ts` `generateShip` when the dungeon's POI is a wreck): mirrored bays along a straight spine (`SHIP_CX`): engine room with reactor drums and an elite guardian at the stern, airlock with the stairs up (`V` portal), crew cabins, side compartments, cargo hold, bridge at the bow; bulkhead and stub doors, crash debris; one level only (`hatch: null`, no sector stairs). Ship chests add salvage (scrap, electronics, rare cores, food, parts). Robots guard the wreck: `DungeonMap.guards` (own RNG stream in `generateShip`: scouts in the spine and cabins, guardians in side compartments and on the bridge, guardians + a repair drone or a sentinel in the cargo hold, an assault construct or sentinel with a repair drone in the engine room); `loadDungeon` sets the robots' env `{ indoor: true }` (no spawning, no despawning, walls and ceilings block them: `roomFor` checks the footprint up to the robot's height `ROBOTS[k].h`, so the heavy ones stay in tall rooms) and calls `spawnGuards` at the wreck's danger (≥ 2); only 2 stray drones. `updateRobots` runs underground too and moves their bolts there (`updateBolts`).
- Angled dungeon decoration (`world/dungeondeco.ts`, from `DungeonMap.boxes` and `style`): all above head height, collision stays on voxels. Temple rooms (h ≥ 5) roll chamfered ceilings, pointed vaults over big halls, raking struts with corner squinches, or plain walls; ship corridors and rooms are always chamfered (octagonal section) with hull ribs, gaps at door frames.
- Terrain LOD: chunks more than 2 chunks away draw grid lines every 4 m instead of 2 m. Distant mountains (`world/sky.ts`) are a fog-free ring that follows the camera.
- Structures are `VoxelGrid.surface(...)` grids: their footprint replaces the terrain (terrain mesh has a hole there, collision uses voxels only).
- Dungeon seeds: `hash(world, ruinId, depth, gx, gz)`; save keys `ruinId:depth:gx:gz`. Save format v3 (`gridWorld.character.v3`; older `gridArena.*` keys are still read), migrations in `save.ts`.
- Vehicles (`data/vehicles.ts` specs incl. price and `enclosed`, `world/vehicles.ts` models/driving): RTV-1 Scout and HTV-6 Mastodon. Bought from Mirek, the dealer at the yard outside Gridholm's north gate (`YARD` in `gen/vehicles.ts`, first free bay), or found abandoned in the wilds (`regionVehicle`, deterministic per region, id `found:rx:rz`; claimed on first use, trunk loot rolled then). Seats: driver = seat 1, the rest wait for multiplayer. Only closed cabs (`enclosed`) shield the driver from drone contact damage (`foeRules.shielded`). Vehicles stay out of the village and ruins. Owned ones are saved in `char.vehicles`.
- Vehicle parts (`VehicleParts` in `data/vehicles.ts`, saved per vehicle): wheel conditions (-1 missing, 0 wrecked), engine, roof cannon. Missing/wrecked wheels or a dead engine stop the vehicle; wear lowers speed. Found vehicles come damaged (rolled from the region seed, visible before claiming). The service window (`ui/service.ts`, E at the vehicle's front) fits Light/Heavy Wheels, Engine Parts and the Vehicle Cannon. Mirek sells parts (`PART_PRICE`) and buys them back at `PART_BUYBACK` (20%); vehicles sell back for half price scaled by condition (`resaleValue`), trunk must be empty.
- Hull and fuel: `VehicleParts.hull` (hull points, max = spec `hull`) and `fuel` (litres, max = spec `tank`). Hull damage goes through `damageVehicle` (bandit/raider bolts, rams, crashes, and contact damage a closed cab absorbs via `foeRules.shieldHit`); at 0 the vehicle is wrecked (immobile, smoulders, driver thrown out) until Hull Plating is fitted in the service window. Fuel is tracked and shown but not burnt yet (`FUEL_BURN = 0` in `data/vehicles.ts`). Old saves get a full hull and tank (`upgradeParts`).
- Game clock (`core/time.ts`, pure): `char.time` in game minutes, 1 real second = 1 game minute (a day = 24 real minutes), runs whenever the game is not paused. Day/night in `world/sky.ts` (`updateSky`): sun and moon on opposite sides of one orbit, stars fade by day, sky/fog colour goes black (night) → dark green (day) with an amber glow at dawn and dusk; underground stays black. The notice board posts every 6 game hours (`boardPeriod`, `char.board.stamp`): the two oldest untaken offers per posting are replaced.
- Creatures (`data/creatures.ts`, `world/creatures.ts`), open world only, unsaved like drones: Ravager packs (flank, dash, bite, retreat; plains), Bramble (territorial ~11 m, head-down charge with knockback, 60% less damage from the front; valleys h < 9), Leechwing (circles ruins/high ground, stalks, dives; flies over terrain), Gnawer (rat-like, long incisors, spined lashing tail; nests of 3–8 turn up anywhere, ~30% of spawns: scurry and sniff, the whole nest swarms in zig-zagging, bites and skitters off, the last one or two flee). Models are PropBatch bodies with origin at the body centre so weapons (`t.g.position`, `t.r`) and EMP (`t.p`) work unchanged; `damageFoe` routes them to `hurtCreature`. Console: `spawn ravager|bramble|leechwing|gnawer`.
- Danger and the threat budget: `gen/danger.ts` (pure) `dangerAt(world, x, z, nearRuin)` = 0 within `DANGER.safe` (60 m) of any village's walls (`villageFar` over `allVillages`), then ~+1 per 280 m, up to 5.5 locally, raised further away from Gridholm (up to +2.5), +0.6 near ruins, capped at 8; `overworld.danger()` wraps it and the HUD place name shows it ("Wilds · danger 3"). Every spawner asks `mayspawn(cost, lv, heat)` in `world/threat.ts`: the threat already within 160 m (creatures, robots, patrol bandits by cost) plus the newcomer must fit `budget(lv)` = 1 + 2.1·lv (noise adds a little), and nothing new spawns for `GRACE` (20 s) after leaving a village. Gates: gnawers and brambles anywhere, ravagers from 1.2, leechwings 2.5, robots per `ROBOTS[k].min`, bandit patrols 2, ambushes 2.5, raiders 3; bandit camps stay ≥ 480 m from villages (`regionInfo`).
- Robots (`data/robots.ts`, `world/robots.ts`, the RD sheet; open world, unsaved; replaced the old field drones, which now only come from repair drones): RD-03 Scout Automaton (danger 1: fast blade packs, flank and slash), RD-01 Guardian Drone (1.8: spider legs, energy cannon, keeps 12–22 m, groups; more near ruins), RD-05 Repair Drone (3: hovers back, heals hurt robots with a beam, deploys up to 2 defence drones), RD-02 Sentinel (4.5: heavy biped, 3-bolt bursts and a crushing blow), RD-04 Artillery Walker (5: shells your position from 16–110 m, a red ring marks the blast; helpless up close), RD-06 Assault Construct (6: charges, hammer smash with knockback). Heavy ones take `armour` 0.55 of damage. Kills drop crystals and salvage (`loot`): Scrap Metal, Electronic Components (`circuit`), Power Core (`pcore`, rare); they count as 'drone' kills for bounties. Robots use `kind: 'robot'` in `foes()` / `damageFoe` → `hurtRobot`. Console: `spawn scout|guardian|repair|sentinel|artillery|assault`.
- Survival (`data/survival.ts` numbers, `world/survival.ts` runtime, HUD bars under HP): stamina (not saved; spent by sprinting, swimming, jumping and blade swings; regenerates after a short pause; at 0 you are exhausted until it is back to 30), calories and water. `char.kcal` is the body's energy store (max `KCAL.max` 3000, start 2400): it burns `KCAL.perDay` (2000) per game day at rest, times the activity (`G.activity`, set by the player's movement: walk 1.6, sprint/swim 4) and the carried weight (`BURN.perKg`), plus one-off costs (jump, blade swing, `burn()`). Below `KCAL.low` you are hungry (slower stamina regen), at 0 you starve (HP drain). Eating adds a food's `NOURISH[k].kcal` and puts its weight (`BULK`) into the stomach (`char.stomach`, `STOMACH.cap` 2 kg, digests 0.3 kg per game hour); `cantEat` refuses food when the stomach is full or the store is near max, so bulky low-calorie food (caps, pods) fills you before it feeds you. Water `char.water` 0..100 as before (drinks do not fill the stomach). Old saves: the 0..100 food bar becomes the same share of `KCAL.max`. The blade hits hard (`BLADE.dmg` 5 vs the Blaster's 1 per shot) but each swing costs stamina; exhausted, swings are slow (`tiredRate`, ignoring any speed bonus) and half as strong. Console: `eat`.
- Weight and bulk (`BULK` in `data/items.ts`: kg and litres per item; `PACK`): the backpack holds `PACK.vol` 40 L (a hard limit: `roomFor`, and the optional `cap` of `putItems` / `putSlot` / `moveStack` / `dropStack` in `inventory.ts`; every way into `char.inv` passes it, e.g. `addItem`, `packRoom`); weight is soft: above `PACK.comfy` (20 kg) you walk slower and sprint costs more, above `PACK.max` (35 kg) you are overloaded (slow, no sprint or jump). Equipped relics and fitted attachments weigh nothing. The backpack and container windows show `loadText()`, item details show kg, L and kcal.
- Food from the wilds: kills drop items besides crystals (`DROPS` in `data/creatures.ts`): only the big herbivore Bramble gives Raw Meat (+ Bramble Plate); Ravager (Hide, Fang), Leechwing (Membrane) and Gnawer (Incisor) give crafting materials (`type: 'mat'`, crafting later; Radek buys them). Raw meat can be eaten (`RAW_SICK` chance to hurt) or roasted into Roasted Meat at any fire (E at a bandit camp's campfire or at a fire lit from a Fire Kit, `world/cooking.ts`, unsaved, `FIRE_LIFE`) or by Jan for `COOK_PRICE`. Jan and Radek buy goods (`BUYS` in `data/npcs.ts`, the 'sell' option). Food pickups are lime (`FOOD_COLOR`), materials bone-white.
- Edible plants (RF-01 sheet): F-01 Nutrient Mushroom Cluster (shady forest) and F-02 Alien Fruit Pod Tree (forest edges, low ground) from `gen/flora.ts` (`chunkPlants`, at most one per chunk, cached; plants clear the trees around them via `plantsNear` in `gen/trees.ts`), F-03 Nutrient Crystals in dungeon room corners (`DungeonMap.crystals`, own RNG stream). `world/flora.ts` draws them (the picked part is a separate lime object) and handles E to pick; picked state is `char.harvest[key]` = game time, removed once regrown (`FORAGE` in `data/survival.ts`: caps 12 h, pods 24 h, crystals 48 h). Keys: `shroom|pod:<cx>:<cz>` (canonical chunk), `crys:<dungeonKey>:<i>`.
- Crafting (`data/crafting.ts` pure: `RECIPES`, `craft`, `GATHER`; `ui/craft.ts` window inside the dialogue panel): materials are Log, Stone, Scrap Metal (drones 35%, guardians 3, bandits 30% / leaders always, raider wreck trunks) plus the creature materials. Tools (`type: 'tool'`, carried in the backpack): Hatchet → E at a tree chops it (`world/gather.ts`; 4 blows, big trees 10; logs drop as pickups), Pickaxe → E at a rock with r ≥ `ROCK_MIN_R` (stones). Felled trees / broken rocks are `char.harvest` keys `tree|rock:<cx>:<cz>:<i>` (index in `chunkTrees` / `chunkRocks`, canonical cx; `gatherKey` maps loaded objects to keys), a stump is drawn, the chunk is rebuilt (`rebuildChunkAt`), they regrow after 3 / 2 game days. Stations: every village blacksmith's workbench is a 'forge' (dialogue option 'craft', all recipes); a Workbench Kit sets up a 'bench' in the wilds (`world/benches.ts`, `char.benches`, max 3, E to use, can be packed up again) for the plain recipes (fire kit, tools, flask, medkit, workbench kit). Radek sells Hatchet/Pickaxe and buys logs, stone, scrap.
- Noise (`world/noise.ts`): `makeNoise(at, radius)` for loud things (Blaster shot = gun stat `noise`, 55 m; Suppressor barrel attachment cuts it to ~12 m; vehicle cannon 95 m; EMP 35 m), `onNoise` listeners react: ground creatures (not Brambles) within the radius go to `investigate` the spot (and hunt you if they see you there), Leechwings hear from 1.8× as far, bandits (not ambushers) within 0.8× are alerted, drones within 0.5× give chase. Noise also builds `heat` in world/creatures.ts: more and faster spawns, placed around the noise and sent to investigate it; heat fades over ~25 s. Leechwing flight is steered (turn-rate-limited arcs, banking): soaring loops of 40–55 m radius at ~24 m, spotting prey up to 90 m (with line of sight), stalking in tightening, descending circles, diving, then a long climbing pull-out; with no player about they hunt Gnawers.
- Bandits (`world/bandits.ts`, human enemies built from the NPC figure, amber; the Bandit Boss is red): Gunners keep 12–20 m, strafe and fire bursts of visible, dodgeable bolts; Bruisers rush with blades; each camp has one Boss. They need line of sight, alert their whole group, sometimes flee when hurt. Bolts that hit a closed-cab vehicle damage its engine/wheels instead of the driver. Camps are a POI type (`camp`, `gen/camps.ts`: crates/barricades as voxels for cover, A-frame tents, campfire, stash container `camp:<id>`), placed per region away from the village and from ruins; a cleared camp stays empty for 30 min (`char.camps`). Small patrols roam further out. Console: `spawn bandits`.
- Raiders and ambushes (`world/raiders.ts`, open world, danger ≥ 1 / 0.8): raider vehicles are AI-driven vehicles (`spawnAIVehicle`, `steerVehicle` with obstacle feelers; tinted amber, not claimable while `ai`) with a driver and a roof gunner; they chase from behind, circle and fire bursts, ram players on foot. Shot to pieces they become claimable wrecks (damaged parts, 50% cannon kept, some trunk loot) and the crew bails out as normal bandits. Ambushes spawn on roads ahead of the player: a roadblock (`ambushHit` obstacles for players and vehicles) and bandits lying low (`sight` 18) on both sides. Console: `spawn raider [mastodon]`, `ambush`.
- Quests (`gen/quests.ts` pure generator, `world/quests.ts` progress, `ui/board.ts` window): the notice board on Gridholm's plaza (`VillageMap.board`) shows 4 notices numbered by `char.board.seq` (deterministic per world); up to 3 accepted (`char.quests`). Kinds: bounty (kill N of a kind anywhere, incl. bandits), camp (clear a real bandit camp), hunt (a group + leader — Pack Alpha / Old Bull / Matriarch — at a real spot; `describeSpot` derives the wording and the creature from the terrain there), fetch (a resident errand: talk to the giver, then an item in a real ruin's dungeon — first guardian's room of depth 1 sector 0,0 — or by a real abandoned vehicle's parking spot). Board quests are claimed at the board, errands at the giver. HUD tracker `#qtrack`, gold markers on the maps.
- Containers: chests roll their contents once on first open and keep what the player leaves or puts in (`char.containers`, key `chest:<dungeonKey>:<index>`). Chests, stashes and trunks use the transfer window (`ui/transfer.ts`): container grid on top, backpack below, two-way.
- Item slots (`ui/slots.ts`): every inventory window renders slots with `slotHTML` and gets drag and drop (pointer events: mouse and touch) from `bindSlots`; a press without movement is a click (quick action). Stack moves are pure functions in `inventory.ts` (`dropStack` merges or swaps, `putSlot`). `Slot.c` is the condition of a worn part (tires keep their wear off the vehicle); such items never stack.
- Guns (`data/weapons.ts`, pure): `GunSpec` base stats (damage, interval, range, magazine, reload, zoom) and attachment slots (optic, barrel, magazine); `gunStats` applies the fitted attachments (`char.gunMods`, fitted in the backpack). `world/weapons.ts`: magazine + reload (R / RLD, automatic when empty; reserve ammo unlimited for now), aiming zoom (right mouse / AIM), scope overlay at 3×+, attachments shown on the held gun. Radek the blacksmith sells attachments (`ATTACH_PRICE`).
- Vehicle service (`ui/service.ts`): slots for each wheel's tire, the engine (drop Engine Parts to repair), 2 engine upgrade slots (`ENGINE_UPGRADES`: Turbocharger, Engine Guard; `engineBoost`, `hurtEngine`), the roof mount (cannon) and the hull (drop Hull Plating), plus the backpack. Mirek buys used parts back scaled by their condition.
- `data/` — items, NPC texts, vehicles. `save.ts` — persistence and version migrations.
